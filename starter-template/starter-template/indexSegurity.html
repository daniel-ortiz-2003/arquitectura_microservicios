Seguridad en Arquitecturas Serverless y Microservicios


La seguridad en arquitecturas serverless y de microservicios es esencial para proteger los recursos y datos sensibles. Implementar mecanismos robustos de autenticación y autorización, como JWT, OAuth2 y API Gateways, es clave para garantizar la integridad y confidencialidad de las aplicaciones distribuidas.

🔐 Autenticación y Autorización en Microservicios


  • ✅ JSON Web Tokens (JWT)
    • Los JWT son tokens compactos y auto-contenidos que transmiten información de forma segura entre partes. Se componen de tres partes: encabezado, payload y firma. El payload incluye claims como sub (identificador del usuario), exp (tiempo de expiración) y aud (audiencia). Al ser firmados digitalmente, permiten la verificación de su integridad sin necesidad de almacenar sesiones en el servidor, facilitando una autenticación sin estado (stateless).

  • 🔁 OAuth 2.0
    • OAuth 2.0 es un protocolo de autorización que permite a las aplicaciones obtener acceso limitado a recursos protegidos en nombre de un usuario. Define varios flujos de autorización, como el Authorization Code Grant y el Client Credentials Grant, adaptándose a diferentes escenarios de autenticación. Es comúnmente utilizado junto con JWT para proporcionar tokens de acceso que contienen la información necesaria para autorizar solicitudes.

  • 🧭 Rol del API Gateway
    • El API Gateway actúa como punto de entrada único para las solicitudes a los microservicios, centralizando la gestión de seguridad. Sus funciones clave incluyen:
    1. Validación de Tokens: Verifica la autenticidad y validez de los JWT antes de enrutar las solicitudes a los microservicios correspondientes.
    2. Control de Acceso: Aplica políticas de autorización basadas en los scopes o roles definidos en los tokens.

  • Abrir/Cerrar
  • 3. Reenvío de Claims: Transfiere los claims relevantes a los microservicios a través de encabezados HTTP, permitiendo decisiones de autorización adicionales a nivel de servicio.
    Herramientas populares para implementar API Gateways incluyen Kong, Tyk, Apigee y las soluciones nativas de proveedores en la nube como AWS API Gateway y Azure API Management.

  • 🛡️ Buenas Prácticas de Seguridad
    • Para fortalecer la seguridad en arquitecturas serverless y de microservicios, se recomienda:
    1. Rotación de Claves: Cambiar periódicamente las claves de firma de JWT para mitigar riesgos en caso de compromisos.
    2. Política de Revocación de Tokens: Implementar mecanismos para invalidar tokens antes de su expiración en situaciones como cambios de contraseña o cierre de sesión.
    3. Validación de Scopes: Asegurar que los microservicios verifiquen los scopes o permisos incluidos en los tokens para autorizar acciones específicas.
